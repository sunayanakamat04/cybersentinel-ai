# CyberSentinel AI - Raw Datasets Directory

This directory is designated for raw network intrusion detection datasets (e.g., CIC-IDS2017, CSE-CIC-IDS2018). Raw data files are excluded from Git via `.gitignore`.

---

## 1. Supported Benchmark Datasets

### A. CIC-IDS2017 (Canadian Institute for Cybersecurity)
- **Source**: University of New Brunswick (UNB)
- **URL**: [https://www.unb.ca/cic/datasets/ids-2017.html](https://www.unb.ca/cic/datasets/ids-2017.html)
- **Format**: 8 CSV files generated by CICFlowMeter, capturing 5 days of normal and attack traffic:
  - `Monday-WorkingHours.pcap_ISCX.csv` (100% Benign baseline)
  - `Tuesday-WorkingHours.pcap_ISCX.csv` (FTP-Patator, SSH-Patator)
  - `Wednesday-workingHours.pcap_ISCX.csv` (DoS / Heartbleed: Slowloris, Slowhttptest, Hulk, GoldenEye)
  - `Thursday-WorkingHours-Morning-WebAttacks.pcap_ISCX.csv` (Brute Force, XSS, SQLi)
  - `Thursday-WorkingHours-Afternoon-Infilteration.pcap_ISCX.csv` (Infiltration)
  - `Friday-WorkingHours-Morning.pcap_ISCX.csv` (Botnet ARES)
  - `Friday-WorkingHours-Afternoon-PortScan.pcap_ISCX.csv` (PortScan)
  - `Friday-WorkingHours-Afternoon-DDos.pcap_ISCX.csv` (DDoS LOIC)

### B. CSE-CIC-IDS2018
- **Source**: AWS Open Data / Communications Security Establishment & UNB
- **URL**: [https://registry.opendata.aws/cse-cic-ids2018/](https://registry.opendata.aws/cse-cic-ids2018/)
- **Characteristics**: Large-scale collaborative enterprise network dataset with over 16 million flows.

## 2. Ingestion & Preprocessing Guidelines

1. **Place raw CSVs into this folder** (`data/raw/`).
2. **Execute ingestion cleaning pipeline**:
   ```bash
   python -m cybersentinel.ingestion.preprocessor --input-dir data/raw --output-dir data/processed
   ```
3. **Data Leakage Safeguards**:
   - Avoid random `train_test_split` on identical connection flows (can cause inflated test accuracy due to session replication).
   - Use grouped / time-series splitting or IP pair isolation across folds.
